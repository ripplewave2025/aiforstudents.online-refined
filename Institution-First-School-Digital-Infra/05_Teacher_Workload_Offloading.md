# Teacher Workload Offloading (Workflows + AI Use)

## Goal
Recover teacher time and energy by standardizing repeatable work and using safe AI assistance for drafting and organizing.

## Work categories to offload
A) Planning
- lesson plan scaffolds
- differentiated versions (simple/standard/advanced)
- question bank generation (with verification)

B) Assessment
- quiz creation
- rubric formatting
- feedback comment banks
- result summaries

C) Communication
- circular drafts
- parent message drafts (teacher-controlled)
- meeting agendas and minutes

D) Documentation
- annual plan documents
- evidence folders for inspections
- training certificates tracking

## Low-risk AI use (allowed by default)
- rewrite/simplify text, translate
- create lesson plan outlines (teacher verifies)
- draft worksheets (teacher verifies and adapts)
- create feedback comment suggestions (teacher reviews)
- summarize meeting minutes
- generate checklists and templates

## Higher-risk AI use (restricted)
- any use involving personal data of students/staff
- automated judgments about student ability or discipline
- generating official policy/disciplinary action without human review
- any medical/legal advice content
- any content that could be discriminatory or stigmatizing

## Copy-paste prompt templates (teacher-friendly)
PROMPT 1: Lesson plan scaffold
“Create a 35-minute lesson plan for topic: ____. Grade: ____. Language: ____. Include: objective, hook, steps, 3 checking questions, and a quick exit ticket.”

PROMPT 2: Worksheet generator
“Create a worksheet (10 questions) for topic: ____. Provide: 3 easy, 4 medium, 3 hard. Include an answer key. Ensure questions match NCERT-style.”

PROMPT 3: Rubric
“Create a simple rubric with 4 criteria and 4 performance levels for: ____. Keep it usable for quick grading.”

PROMPT 4: Feedback bank
“Generate 20 short feedback comments for student work on: ____. Group by: strengths, improvements, next steps.”

PROMPT 5: Meeting minutes
“Summarize these notes into: decisions, action items with owner and deadline, and risks: ____”

## Platform workflows (Google/Microsoft neutral)
WF1: Weekly planning template (one shared doc per week)
WF2: Meeting minutes (single template; shared folder)
WF3: Assessment via forms (auto summary)
WF4: Resource bank (tagged by grade/topic)
WF5: Monthly report one-pager (auto from templates)

## Evidence to collect (for pilot proof)
- 3 examples of reused worksheets
- 3 meeting minutes with action closure
- 1 assessment form + summary
- teacher self-reported time saved logs
