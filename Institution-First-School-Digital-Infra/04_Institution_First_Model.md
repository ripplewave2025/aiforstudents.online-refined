# Institution-First Model

## Definition: “Put the school online”
To establish the school as a digitally present, administratively functional institution with continuity across staff changes.

## Minimum Viable School Online (MVSO) stack
1) Identity
- domain name
- official email pattern (eg, name@schooldomain)
- website landing page (basic)

2) Administration
- one admin-of-record (not personal, documented handover)
- recovery methods documented (second admin, phone, recovery email)
- onboarding/offboarding checklist

3) Institutional repository
- shared drive / document vault
- folder structure and ownership rules
- template library (circulars, lesson plans, assessment formats)

4) Communication
- staff group channel (email list / Teams / group)
- calendar for meetings + school events
- meeting notes template

5) Teacher workflows
- standard forms for attendance, feedback, and simple assessments
- reporting template and weekly pulse rhythm

6) Responsible AI staff layer
- allowed use cases
- restricted use cases
- data handling rules
- verification expectations

## Design requirement for low-resource contexts
- Works with 1 shared laptop + phone hotspot
- Offline-first: documents downloadable, printed when needed
- Minimal dependencies on student devices

## Success indicators
- 90% staff accounts active
- 1 shared repository used weekly
- 5 workflows adopted by teacher champions
- basic reporting working (weekly)
