# Lamahatta Pilot Plan (30/60/90 Days)

## Pilot scope
Teacher and institution only:
- institutional identity and workspace
- teacher workflows and PD
- governance and responsible AI staff usage
- metrics and reporting

## Pilot roles (fill names)
- School Signatory:
- Admin Steward:
- Teacher Champion A:
- Teacher Champion B:
- Program Lead:
- Support contact:

## Day 0–7: Setup + readiness
- Confirm signatory approval
- Decide stack (Google-first or Microsoft-first)
- Create domain plan (or confirm existing)
- Create admin accounts (2 admins)
- Draft folder structure and permissions
- Baseline survey of teachers (time, pain points, device access)

## Day 8–30: Core backbone + 5 workflows live
Backbone:
- Staff accounts created and activated
- Shared repository used weekly
- Calendar and meeting minutes running

Workflows:
WF1 weekly plan
WF2 minutes + action tracking
WF3 forms-based quizzes
WF4 circular template + archive
WF5 monthly report template

## Day 31–60: Expand adoption + community rituals
- Train remaining teachers in the 5 workflows
- Run 4 weekly rituals
- Build template library (minimum 20 assets)
- Add responsible AI quickstart for staff

## Day 61–90: Proof and replication
- Freeze v1 templates
- Produce a pilot report packet (metrics + artifacts)
- Document onboarding/offboarding process
- Identify minimum replication kit for next school

## Milestones checklist
- M1: domain + admin ownership done
- M2: 80% staff accounts active
- M3: 5 workflows used weekly by champions
- M4: weekly review running without external push
- M5: pilot proof packet ready

## Risks and mitigation
- Connectivity weak → offline templates + low-bandwidth workflows
- Low teacher time → micro-sessions + champion-led adoption
- Account loss → 2-admin recovery process and documentation
- Tool anxiety → start with 2 workflows, expand to 5
